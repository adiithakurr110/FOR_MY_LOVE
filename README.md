# ❤️ For Uh My Love

An interactive romantic web experience built to express love through code, animations, and melody.

---

## 🌐 Overview

**For Uh My Love** is a modern, responsive web experience crafted as a heartfelt digital expression of love. It features purple-pink ambient glowing gradients, interactive floating love notes, synchronized romantic lyrics, and soothing background music.

---

## ✨ Features

- **Personalized Romantic Aesthetic:** Deep purple and rose ambient gradients, twinkling stars, and glowing pulsing hearts.
- **Interactive Surprise Reveal:** Clicking *"Open it"* reveals an unfolding romantic love note with interactive floating heart bursts.
- **Synchronized Lyrics Experience:** Ethereal animated lyrics that flow seamlessly with the background song.
- **Audio Integration:** Seamless background music synchronized with the interactive reveal.
- **Fully Responsive:** Smooth 60fps animations optimized for all mobile and desktop screen sizes.
- **Replay Journey:** Option to send love back and replay the entire experience anytime.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **UI & Animations:** [React 19](https://react.dev/), [Framer Motion](https://www.framer.com/motion)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Shantell Sans via `next/font`

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## ☁️ Deployment on Vercel

The easiest way to deploy this Next.js app is using [Vercel](https://vercel.com):

1. Push your repository to GitHub.
2. Sign in to [Vercel](https://vercel.com/) with GitHub.
3. Import this repository.
4. Keep standard Next.js build presets and click **Deploy**.
